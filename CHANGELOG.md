# Changelog

## Deep foundation — 2026-10-04
- Established Plugin Builder as a specialist plugin-creation system.
- Built 18-lobe / 144-neuron knowledge architecture.
- Integrated current Plugin Creator operational lessons without making the built-in creator a hard dependency.
- Added current OpenAI/MCP/Agent Plugins, OAuth, security, HCI, accessibility, testing, operations, update and submission knowledge.
- Added selective-retrieval runtime draft, source registry, evaluation boundaries, templates and static validators.

## Builder expansion — 2026-10-04
- Expanded the brain from 18 lobes / 144 neurons to 20 lobes / 160 neurons.
- Added Architecture Search & Synthesis with feasibility filtering, dominance pruning, failure simulation, build-vs-reuse, and architecture proof.
- Added Host Installation & Release Adaptation with capability discovery, adapter selection, guarded mutation, connection separation, read-back verification, and failure recovery.
- Added native portable plugin scaffold, validator, deterministic packager, and regression tests.
- Changed the runtime lifecycle to contract → architecture search → canonical build → verification/repair → package → real host adapter → read-back/smoke verification.
- Kept official host creators/installers as optional mutation/compatibility adapters rather than the source of Plugin Builder intelligence.


## ChatGPT package v0.2.0 — 2026-10-04
- Added reproducible ChatGPT plugin packaging from the canonical GitHub source.
- CI now builds and inspects `Plugin-Builder-ChatGPT-v0.2.0.zip` on every push.
- The package includes 20 lobes / 160 neurons, NEURON_MAP, native authoring tooling, architecture search, installation adapters, and the comparative builder benchmark.
- Package readiness is tracked separately from account installation/read-back verification.


## Creator parity v0.3.0 — 2026-10-04
- Expanded the brain to 21 lobes / 168 neurons.
- Added Plugin Lifecycle Execution & Creator Parity lobe.
- Added explicit parity workflows for private create, metadata/files inspection, archive/history retrieval, release listing, guarded account update, source-owner routing, create-route coverage, and public submission preparation.
- Added `CREATOR_PARITY_MATRIX.md` and creator-parity execution contract.
- Added valid ChatGPT/Codex skill metadata to the runtime package.
- CI now builds and verifies the reproducible ChatGPT v0.3.0 artifact.
- Retained Plugin Builder-only architecture search, failure simulation, adversarial assurance, deterministic native tooling, repair regression, and post-install verification.


## Command layer v0.3.1 — 2026-10-04
- Added safe creator-style command aliases including `create_personal_plugin(mcp_url=...)`.
- Added `references/command-layer.md` with canonical remote-MCP → package → adapter → read-back workflow.
- Added `scripts/command_layer.py` using AST literal parsing; no eval or invented host actions.
- Added regression tests for URL validation, embedded credentials, unknown arguments, and code-execution rejection.
- CI builds and verifies `Plugin-Builder-ChatGPT-v0.3.1.zip`.
- Account mutation remains adapter-dependent; package readiness is reported separately from installation.
